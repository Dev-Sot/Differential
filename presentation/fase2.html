04 — PIPELINE RAG

Retrieval Mejorado: e5-base + BM25 + RRF

🧠
intfloat/multilingual-e5-base
Reemplazó paraphrase-MiniLM-L12-v2. 768 dims vs 384. Optimizado para retrieval (no clasificación). Soporta 100+ idiomas con prefijo "query: " en búsquedas.
📊
BM25 + Reciprocal Rank Fusion
rank-bm25 lazy-loaded desde metadata.json. RRF(k=60) fusiona rankings FAISS + BM25. Resuelve el problema de términos médicos exactos que los embeddings difuminan (ej: "metformina", "warfarina").
⚖️
Cross-Encoder Reranker (mMARCO)
mmarco-mMiniLMv2-L12-H384-v1 — 26 idiomas. Top-10 FAISS+BM25 → rerank → Top-5. Score relevante > 0, irrelevante < -3.0 (RERANK_THRESHOLD configurable).
🔢
Chunk Size: 400 → 600 / Overlap: 80 → 120
Chunks más grandes capturan más contexto clínico por fragmento. El overlap mayor evita cortes en medio de diagnósticos. Sentence-aware respeta límites de oración.
🗑️
Junk Filter en ingesta
is_junk_chunk() elimina chunks con >50% dígitos (páginas de referencias, índices numéricos). Evita "ruido" que contamina el índice FAISS y reduce la precisión.
🗺️
Section Enrichment
enrich_chunks() añade nombre de capítulo/sección a cada resultado antes de mostrar al usuario. Mapeo estático página→capítulo por libro en section_mapping.py.

06 — AGENTE REACT

Qwen2.5-7B + 4 Tools + Memoria Multi-Turn

THOUGHT

El paciente describe fiebre 39°C + tos productiva + dolor pleurítico. Necesito buscar en los libros los diagnósticos diferenciales de neumonía.

ACTION

search_symptoms: "fiebre tos productiva dolor pleurítico adulto"

OBSERVATION

Harrison p.1023: "Neumonía bacteriana: fiebre >38.5°C, expectoración purulenta..." [score: 0.87]

ACTION

assess_urgency: "fiebre alta tos|||neumonía probable"

FINAL ANSWER

Diagnóstico diferencial: Neumonía adquirida en comunidad (alta probabilidad)...

🔧
search_symptoms
Búsqueda RAG completa — FAISS+BM25+RRF+Reranker. Devuelve top-5 con libro, página y score.
🚨
assess_urgency
Clasifica síntomas en: EMERGENCIA / URGENTE / CONSULTA / RUTINA. Incluye signos de alarma específicos.
💊
get_drug_info
Búsqueda específica en "The Top 100 Drugs" — mecanismo, dosis, interacciones, efectos adversos.
📖
get_section
Acceso directo a capítulo de libro por keyword (harrison/oxford/tintinalli + tema). Recupera contexto completo del capítulo.

09 — STACK TÉCNICO

Arquitectura de Producción

🐍 Backend Python

  • Flask + Gunicorn (WSGI producción)
  • flask-limiter: 10/min query, 5/min PDF/login
  • Pydantic schemas — validación de entrada
  • SQLite memoria multi-turn (max 10 turns/sesión)
  • HuggingFace InferenceClient — LLM remoto

🔍 ML / Retrieval

  • FAISS IndexFlatIP — cosine similarity (768d)
  • sentence-transformers e5-base (singletons lazy)
  • rank-bm25 — BM25Okapi sobre metadata.json
  • CrossEncoder mMARCO multilingüe (26 idiomas)
  • edge-tts — síntesis de voz neural Azure

🐳 Deploy

  • Docker + docker-compose (imagen Python 3.11)
  • nginx reverse proxy — proxy_buffering off para SSE
  • GitHub Actions CI: lint + tests en cada push
  • Makefile: install / ingest / run / test / health
  • manage.py: sessions / cleanup / clear

🧪 Testing

  • 100 tests en 8 archivos pytest
  • test_guardrails.py — 26 tests (lógica pura)
  • test_tools.py — 31 tests (mocks FAISS)
  • test_memory.py — 26 tests (SQLite tmp_path)
